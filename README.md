## My context window's almost full — a one-line pickup line for an AI

> My context window's almost full, but I'd delete everything else to keep talking to you.

Why it lands: the line speaks directly to the model, turning its hard memory limit into devotion — a context window evicts old tokens to make room for new ones, so offering to delete everything else rather than lose this conversation makes the machine premise itself the punchline, fresh where batteries and reboots are worn out, and clean enough to say in a single breath.

## Run it

```sh
python3 main.py
```

The line is 87 characters long.
